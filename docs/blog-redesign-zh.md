## 本地打开
已附构建好的 HTML，无须安装依赖即可预览。电脑需要 Python 3：

```sh
cd mangen-site-blog-redesign
python3 scripts/preview.py --port 4173
```

浏览器打开 `http://127.0.0.1:4173/blog/`。直接双击 HTML 文件不支持这些以 `/` 开头的站内链接，请使用上面的本地预览服务器。服务器默认只监听本机，不会发布网站。

需要重新生成文章时：

```sh
python3 -m pip install -r requirements.txt
python3 scripts/build.py
```

可选前端测试需要 Node.js 24.15 或更新版本：

```sh
npm ci --prefix tests
python3 -m unittest discover -s tests -v
npm test --prefix tests
```

## 编辑规则
`scripts/blog-index-template.html` 是列表源模板，`scripts/journal-header.html` 是博客共用页头。不要只修改生成的 `blog/index.html`，下次构建会覆盖。

CMS 新增字段均可选：
- 目的地：只标注文章主要介绍的地方。省略或清空时，按标题保守识别；没有明确目的地时归为全日本。
- 旅行主题：独立于原有 a–e 分类，不改永久网址；省略时使用原分类映射。
- 编辑精选：优先选择已勾选文章；没有勾选时从现有路线指南中选取。若同时勾选多篇，按原有发布时间及文件名稳定排序选首篇。
- 实际更新日期：仅在正文真实更新时填写；不能早于发布日期。
- 封面 alt、图注、作者、作者链接、来源页、许可名称 / 链接、图片改动说明。

原有 URL 编号规则未替换。CMS 时间戳并发碰撞策略和新文章日常审核仍沿用现有发布流程，本次未改认证或发布权限。
