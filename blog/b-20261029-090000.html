11月7日东京至品川横须贺线停运：成田N’EX与镰仓行程怎么改

发布于 2026-10-31 · 东京 / 横滨 / 镰仓 / 成田 · 交通接送 · 株式会社万源

2026年11月7日横须贺线东京—品川区间终日停运，成田N’EX改在东京站折返，影响还延伸至11月6日晚和8日清晨。按出发站、机场航班与镰仓行程分别检查，别把区间停运当成全线停摆。

本文目录

  2. 2. 坐N’EX去成田，别仍在原站等直达车
  3. 3. 影响还包括11月6日晚与8日早晨
  4. 4. 这次不提供其他铁路公司的振替输送

2026年11月上旬安排东京、横滨或镰仓旅行，先把11月7日圈出来。JR东日本已公布，当天横须贺线东京至品川区间从首班至末班停运，原因是隧道集中修缮；这不是横须贺线全线停运，成田机场的铁路服务也并未全部停止。真正需要重排的是经过这一段的直达行程，以及原本准备在新宿、品川、横滨等站搭乘成田特快N’EX的安排。JR东日本施工专页

1. 先看区间：东京与品川之间不能照原线直通

11月7日，横须贺线在品川站向横滨、久里浜方向折返；总武快速线在东京站向千叶方向折返。JR公告说明，品川至久里浜、东京至千叶保持通常运行班次数，其他线路按原计划运行。东京至品川之间可利用东海道本线、山手线或京滨东北线等路线衔接，但当日临时运行情况仍须出发前再查。JR东日本计划停运清单

例如住在东京站附近、当天去镰仓，可以在查询器中输入准确的11月7日，比较先到品川再换乘的路线；若住在新宿，则按实际出发站查询，不必为了避开这一小段，反而先绕到东京站。路线选择要看车次目的地和换乘位置，不要只认“横须贺线”几个字，也不要拿平日截图直接当当天时刻表。

带婴儿车或大行李时，多一次换乘的影响常在上下楼和找站台，而不只是列车行驶时间。可以先确定去程和返程各在哪一站换车，再查询电梯路径；若本来把镰仓、江之岛和横滨夜景挤在同一天，这天更适合删掉一段远距离移动，而不是把所有停留都压缩。普通观光路线仍可参考镰仓江之岛行程安排，但以这次施工日的交通查询结果为准。

2. 坐N’EX去成田，别仍在原站等直达车

11月7日，成田特快N’EX的东京至大船、新宿区间停运，列车改在东京站与成田机场之间折返。JR说明，东京至成田机场仍按通常班次数运行。因此，住新宿或横滨并不意味着不能乘N’EX去机场，而是需要重新安排前往东京站的这一段，并确认从东京站出发的指定车次与座位。JR东日本停运区间与折返安排

已经购票的人，先查看订单里的乘车站、日期、车次与有效区间，再按原购票渠道确认变更或退款办法。不要默认一张原本写着“新宿出发”的票，可以不经确认直接换成任意东京出发车次。同行者若分别买票，也要一起核对，避免只有一人的乘车站改好，其他人仍按旧计划到站。

当天从成田抵达日本同样受影响。若原计划坐N’EX直达新宿或横滨，需把东京站之后的接续写进到店时间；深夜抵达、带孩子或已经约好接送的人，还应更新自己的预计到达时刻。机场交通与市区移动最好分开查，别只看到“成田机场到东京”的时间就结束规划。

3. 影响还包括11月6日晚与8日早晨

N’EX的变更不只限于星期六。官方专页列出的总体影响范围，从11月6日约19:40至11月8日约8:00，均按东京站时刻说明；前一晚与后一早仍有个别按通常方式运行的列车，所以不能把这一时间窗内的每班车一概认定为相同终点。JR东日本分日车次表

具体例子是，11月6日成田机场18:45出发的N’EX 46号列车，按公告运行至东京站19:45到达，东京以后至大船、新宿的区间停运。11月8日早班也应逐班核对，不要认为过了11月7日午夜便全部恢复原直通安排。对于早航班，先确认能到达机场的实际列车，再倒推退房和出门时间，比临时赶到熟悉的站台更稳妥。

4. 这次不提供其他铁路公司的振替输送

JR东日本说明，本次施工不实施向其他铁路公司的振替输送。可以自行比较其他公司的路线，但不要据此认为原有JR车票一定可免费用于别家线路。若持铁路周游券或其他特别票种，应查看该票券覆盖范围，费用和改乘规则以铁路公司的正式说明为准。JR东日本施工注意事项

遇到计划之外的延误时，可结合日本电车延误或停运应对分清运行公告、改乘路线与原票处理。

出发前做三次检查即可：订行程时输入实际日期；前一晚确认预订车次与酒店出发时间；当天查看JR运行信息和车站指示。计划性停运可以提前避开，但天气、临时故障和人流仍可能改变所需时间。赶国际航班时，不要用市区换乘所剩的最后几分钟去抵消航空公司的值机截止。

本文核查于2026年10月31日，依据JR东日本已公布的11月施工计划。本文没有查询或保证某个车次的实时余票，实际搭乘请以铁路最新公告及订单信息为准。

资料核对：2026-10-31（日本时间）。营业、交通、商品及现场规则可能调整，出行前请再核对文中官方来源。
